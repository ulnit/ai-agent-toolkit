📦 What's Inside

🌐 web-fetch

Fetch any URL, extract clean readable text. Strips HTML, scripts, ads. AI-ready output.

$ agent-tools web-fetch "https://example.com"

📋 json-query

Query JSON with simple dot notation. No jq syntax to learn.

$ agent-tools json-query data.json "users.0.name"

👁️ file-watch

Watch directories, trigger commands on file changes. Auto-build, auto-deploy.

$ agent-tools file-watch ./src "make build" -p "*.py"
